## Unlocking Infinity Dimensions

Infinity Dimensions unlock by reaching certain antimatter thresholds.

## Purchasing

Infinity Dimensions are only purchasable in sets of **10** and cost Infinity Points. Each set gives a permanent multiplier — similar to Antimatter Dimensions — but the size of the multiplier depends on which Infinity Dimension you're buying.

## Production

Each Infinity Dimension produces the next lower one, just like Antimatter Dimensions.

Every crunch, the *produced* amount of each Infinity Dimension is reset to whatever you've purchased. While the production doesn't carry between crunches, the multipliers you bought do.

## Notable details

Instead of producing antimatter, the **1st Infinity Dimension** produces a separate resource called **Infinity Power**, which is applied to all Antimatter Dimensions as `power^7`. Infinity Dimensions themselves are *not* affected by Tickspeed Upgrades.
