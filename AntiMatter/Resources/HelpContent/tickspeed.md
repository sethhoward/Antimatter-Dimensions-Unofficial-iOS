Production in the game happens on each "tick", initially once per second. Buying **Tickspeed Upgrades** speeds Antimatter Dimensions up — as if multiple ticks pass each second.

## Tickspeed

States how many game ticks are occurring every second. Fractional ticks are accounted for — part of a tick still boosts production. The displayed tickspeed time is simulated; the game's actual update rate is set in Options.

## Cost

The cost of antimatter to multiply ticks/sec by the displayed multiplier. Without any Antimatter Galaxies the cost increase per purchase is roughly **×1.125**.

## Buy Max

Buys the maximum number of Tickspeed Upgrades you can afford with current antimatter.
